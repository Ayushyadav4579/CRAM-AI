# CRAM AI V2

Mobile-first AI study material generator.

## Included
- TXT, PDF and DOCX text extraction
- Topic/chapter detection
- Selectable output formats
- Up to 100 requested items per generation in the UI
- Notes, short notes, MCQs, short/long answers, T/F, fill blanks, flashcards, quizzes, mind maps, definitions, formulas and difficult words
- English/Hindi output
- AI generation through a server route
- Document chat endpoint
- Local browser history
- Responsive dashboard-style UI

## Run
npm install
copy .env.example to .env.local
add GEMINI_API_KEY
npm run dev
