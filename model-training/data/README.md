# Data input policy

Do not put copyrighted textbooks here unless you have permission. Add a JSONL source file with one object per line:
- text (required)
- source_id (required, stable identifier)
- subject, grade (optional)
- license (required provenance label)
- source_url (optional)

Use your own notes, user-supplied documents, or sources with explicit reusable licenses. Do not treat generated templates as fact-checked. Keep evaluation sources grouped separately by source_id. The repository intentionally does not bundle scraped textbooks or fabricate a large corpus.
