# CRAM AI
A mobile-friendly Next.js starter for an AI study-notes/question generator.

## Run
1. Install Node.js 20+.
2. `npm install`
3. Copy `.env.example` to `.env.local`.
4. Add your Gemini API key.
5. `npm run dev`
6. Open the local URL in your browser.

## AI
The starter uses the Gemini API through a server-side Next.js route. The API key is never placed in client-side code.

## Important
This is a production-oriented starter, not a complete SaaS backend. Authentication, PostgreSQL persistence, payments, cloud storage, email verification and admin RBAC need to be connected before public launch.
